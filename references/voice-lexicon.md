# 口吻词表（按文章类型）

> 2026-08-17 从发布版 + 语料对照固化。脚本：`scripts/voice_match.py`。
> 朱雀是硬验收，口吻是过检方法。词表用来写反应句，不要整段搬。

## 长文实测

用：这家伙 / 话不多说 / 咱们现在开始 / 哎实在没办法 / 那我来吧 / 然后没想到 / 挺香 / 好嘛 / 就这 / 弄好了 / 还是得我 / 根本过不去 / 随口问 / 完全 ok / 咔咔 / 那验证啰

不要：它查了 / 回来说 / 它解释了 / 它马上切 / 掰开讲 / 它先回 / 摸完一圈 / 它捋的逻辑 / 以它的脑子

「说白了」一篇最多一次，当短判断。

## 数据复盘

用：这意味着啥 / 不是的 / 这还没完 / 有好的该夸夸 / 不咋地的点 / 我看看 / 对对 / 这个靠谱

不要：说白了 / 话不多说 / 哎实在没办法 / 这家伙 / 咱们现在开始

## 贴图

短句 + 一句判断 + hashtag。不要套五拍，不要长分析。

## 教程

用：一步步 / 别怕 / 没想到还真成了 / 试水 / 嚯个茶

不要编：香哈哈 / 奈斯 / 嘎嘎香 / 贼拉香（语料和发布版里几乎没有）
