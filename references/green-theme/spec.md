# 萌绿主题样式规范（存档）

> 来源：2026-06-23 已发布《windows电脑轻松配置正版AI龙虾》的最终样式。
> 实现：`scripts/push_article.py` 的 `render_markdown_to_green_html` + `green_*` helpers + `mac_code_block`。
> 真实样板 HTML：`green-theme/published-sample.html`（微信发布后抓回，样式被微信完整保留）。
> 用法：`push_article.py --theme green`。

## 整体
- 背景：**纯白 `#ffffff`**（不是渐变；和紫色主题的 `#fdf4ff→#f5f3ff` 渐变区别开）
- 字体：-apple-system / PingFang SC 等；正文行高 1.8

## 子标题（核心特色：居中 + 上下装饰线）
- `## H2` → 绿色 `#48b378`、**居中**、19px 加粗
  - 标题**上方**一条居中短线：宽 34px、`#a7e0c0`（浅绿）
  - 标题**下方**一条居中短线：宽 48px、`#48b378`（深绿）
- `### H3` → 绿色 `#48b378`、左对齐、17px 加粗

## 正文 / 强调
- 段落：深灰 `#3f3f3f`（萌绿原版正文色）
- `**强调**` → `#4a4a4a` 深灰加粗（注意：不是绿色，避免满屏绿）
- 行内 `` `code` `` → 绿字 `#28ca71` + 浅灰底 `rgba(27,31,35,.06)` + 圆角 4px + 等宽字体

## 代码块（仿 Mac 窗口）
- 外层圆角 6px + 投影 `rgba(0,0,0,.55) 0 2px 10px`
- 顶栏深色 `#282c34`，左上角三个**字符圆点 ●**：红 `#ff5f56` / 黄 `#ffbd2e` / 绿 `#27c93f`
  - ⚠️ 用 `●` 字符（带文字的 span，微信一定保留），**不要用空 span 画圆点**（微信会过滤背景）；也**不要用外链 svg**（微信正文只显示 mmbiz 图，外链 svg 不显示）
- 代码区深色 `#282c34`，文字浅灰 `#abb2bf`，等宽字体，横向可滚动

## blockquote / 分隔 / 图片 / 图注
- 引用块：浅绿底 `#f0f9f4` + 左边框 `#48b378`(4px) + 文字 `#3f3f3f`
- 分隔线：绿色渐变（透明 → `#a7e0c0` → 透明）
- 图片：居中、圆角 10px
- 图注：灰 `#999`、居中、13px

## ⚠️ 正文没有 `## 小标题` = 看不出是萌绿
- 居中绿标题是萌绿唯一的大面积绿色元素；纯段落平铺的文章渲出来通篇白底黑字，用户会以为没用绿主题（2026-07-13 实翻车）。
- 写稿时至少 3~4 个短小标题；推前 `--dry-run` 后 `grep -c '#48b378' dry.html` ≥ 2 再推。

## ⚠️ 重排旧文的已知坑
- 旧文 `content.md` 里若有**硬编码 inline HTML**（如文末"相关文章"居中链接 `<a style="color:#7c3aed">`、手写签名），`render_*` 会**原样透传**，导致萌绿版里**残留紫色 `#7c3aed`**。
- 处理：重排旧文前，先把 content.md 里的 inline `#7c3aed` 等紫色改成 `#48b378`，或删掉这些 inline 块让渲染器统一接管。
