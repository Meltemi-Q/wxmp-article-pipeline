# 风格统计约束（anti-AI stylometry）

> 2026-08-16 固化。来源：朱雀 AI 检测实测（用户发布版=「人工创作特征显著」，AI 各版=「较弱」）
> ＋ `scripts/style_fingerprint.py` 对三篇发布版基准（2026-08-08 / 08-10 / 08-15）的量化对比。
> 核心认知：**AI 味的本质是统计上的「过度均匀 / 模板化」，不是某个词用错。**

## 基准数值（宇龙发布版，长文）

| 指标 | 发布版区间 | AI 初稿实测 | 说明 |
|---|---|---|---|
| 段首最高频字占比 | 6%~9% | 27% | 「我问…」「它答…」轮流开头 = 最大 AI 特征 |
| 冒号 /百字 | 0.27~0.59 | 1.26 | 「我说：」「它回：」引导句泛滥 |
| 问号 /百字 | 0.05~0.23 | 0.68 | 引原话问句太密；用户成稿会把提问陈述化 |
| 逗号 /百字 | 4.4~4.6 | 5.6 | 冒号简单换逗号会爆逗号，要用句号断句 |
| 段尾句号率 | 16%~31% | 10%（删过头）/ 100%（原始） | 混合才像人：默认不带，约 1/5 自然收口带 |
| 相邻段同首字 | 2%~5% | 6% 或 0% | 全重复和全不重复都是「整齐」 |

## 写作硬约束（写完自查，QC 的 stylometry 会兜底）

1. **段首换着开头**：动词/名词/状语/「就这？」都行，同一个字开头的段落不超过 15%。写完扫一眼每段第一个字。
2. **冒号限量**：「我说：/它回：」这类引导句一篇最多七八处，其余改叙述（「查完跟我说，…」「回来说…」）。
3. **问号限量**：只留真问句（原话里的关键质问、结尾互动句），转述的提问改陈述。
4. **句号混合**：段尾默认不带「。」，但每四五段留一个自然收口句带句号；图注一律不带。
5. **长句用句号断**，不要无限逗号串联。
6. **图注写描述不写金句**：说图里是什么，不写对仗总结。
7. **图片内容不复述**：参数、选项、界面文字留给图，正文一句带过。

## 工具

```bash
# 指纹对比（交付前跑，OFF 项应为 0；基准文本一行一段的纯文本）
python3 scripts/style_fingerprint.py \
  --baseline <发布版1.txt> <发布版2.txt> <发布版3.txt> \
  --target <本篇纯文本.txt>

# QC 已内置 stylometry 检查（news 且 ≥15 段时生效），hits 非空每条扣 4 分
python3 scripts/wxmp_article_contract_qc.py --expected-images ... --output article.md
```

基准文本更新：每次用户发布后，把新发布版提纯加入基准池（保持最近 3~4 篇长文），老口径淘汰。

## 朱雀检测（matrix.tencent.com/ai-detect）

- 免登录每天 5 次；结果只有三档：人工创作特征显著 / 较强 / 较弱。
- 实测：AI 稿即便过了上面全部统计约束，也可能仍判「较弱」——深层统计特征（词序分布）改写不掉。
- **发布前用户快速手改一遍是最可靠的过检方式**（8/15 篇 30 处手改即从「较弱」到「显著」）。
- 用法：正文纯文本贴入检测；结果记进草稿 manifest，仅作参考不作门槛。
